GLOSSARY & READING GUIDE — 
"Semester Spread & Structures" workbook
(Context for the Academic Advisor Bot. Items

1. What the workbook contains
•
The workbook describes the 4-year B.Tech Data Science ("DS") curriculum, one version per 
admission batch: 2022, 2023, 2024, 2025, 2026.
•
The year in a sheet name is the student's BATCH (year of admission), not the calendar year 
in which a course is taught. A student admitted in 2024 follows "Sem_Spread_2024" and 
"Struct_2024" for all 8 semesters. <<CONFIRM>>
•
Two kinds of sheets:
◦
"Sem Spread" / "Sem_Spread_<year>" (Semester Spread) = which course is taken in 
which semester (S1–S8), with code, prerequisite, L-T-P-C and basket.
◦
"Struct_<year>" (Credit Structure) = the list of courses and credits inside each 
basket, and the minimum credits per basket needed for the degree. It does not say 
which semester a course is in.
•
The curricula differ between batches. Always answer using the sheets for the student's own 
batch.
2. Column headers and abbreviations
•
S1, S2 ... S8 = Semester 1 to Semester 8 (2 semesters per year, 4 years).
•
SEMESTER - I / SEMESTER - 2 ... = same as S1, S2 ...
•
SUMMER = summer break between semesters (after S2, after S4 and after S6). No regular 
courses are listed in it.
•
Course Code / Code = unique course identifier, e.g. COMP201. "DATA 301" and 
"DATA301" are the same course (the space is a typo).
•
Course = course title.
•
Pre-Req = prerequisite: a course that must be completed before this course can be taken. 
Several codes separated by commas (e.g. "COMP204, COMP207") means ALL of them are 
required.
•
NIL / Nil = no prerequisite.
•
L = Lecture hours per week.
•
T = Tutorial hours per week.
•
P = Practical / Lab hours per week.
•
C = Credits for the course.
•
L-T-P / "LTP: 3-0-2" = Lecture-Tutorial-Practical hours per week, written in that order. 
"LTP: 3-0-2" means 3 lecture hours, 0 tutorial hours and 2 lab hours per week.
•
Credit rule (holds for almost every course): C = L + T + (P ÷ 2). Example: 3-0-2 → 4 
credits; 2-0-4 → 4 credits; 1-0-2 → 2 credits. <<CONFIRM>>

•
An L-T-P of 0-0-0 with credits > 0 (e.g. Sustainable Cities and Communities 0-0-0-3, 
Human Values in Work and Life 0-0-0-2, Language 0-0-0-3, Community Engagement 
0-0-0-1, internships and projects) means the course has no regular weekly classroom hours. 
It is delivered as <<CONFIRM: online / MOOC / workshop / activity-based / self-paced>>.
•
Total (row) = sum of L, T, P and C for that semester.
•
Total HRS = weekly contact hours in the semester, i.e. L + T + P summed over all courses in 
that semester.
•
Total Credits (last column) = credits in that row. The final column per basket = basket total.
•
Fixed Min = minimum credits required from that basket to graduate.
•
Credit Structure (for award of the Degree) = minimum credits per basket needed to earn the 
degree. The total is always 180.
•
Cr = Credits.
•
= serial number in a list.
•
TBA = To Be Announced (course code or details not yet decided).
•
"/" between two courses (e.g. "PSYC101/ECON101 — Introduction to Psychology/
Introduction to Economics") = the student takes ONE of the two options.
•
"/" inside a Specialization Track cell (e.g. "MATH401/COMP401 — Probabilistic Graph 
Models / Web Framework") = the first option is for Track #1, the second for Track #2. The 
prerequisites are given in the same order (e.g. "DATA301/NIL" → Track 1 needs DATA301, 
Track 2 has none).
•
When a course name carries its own "LTP: x-y-z", that overrides the L/T/P numbers in the 
columns (the columns show only one option's hours).
•
"#1 Course", "#2 Course" = the 1st, 2nd ... course of that type in sequence.
•
SPT = SPecialization Track. "SPT-Course #3" = the 3rd course of the student's chosen 
specialization track.
•
SPIL = Socio-Cultural Perspectives on Indian Life (course UCOR205).
•
MLOps = Machine Learning Operations (deploying and maintaining ML models in 
production).
•
AI = Artificial Intelligence; ML = Machine Learning; NLP = Natural Language Processing; 
IoT = Internet of Things; EDA = Exploratory Data Analysis.
3. Baskets (course categories). Every course belongs to exactly 
one basket.
•
Basket = a category of courses with a minimum credit requirement. B1–B7 are basket IDs.
•
B1 – Univ Core / University Core (UCOR courses) = compulsory courses that every student 
of the university takes, whatever the programme (communication, writing, critical thinking, 
design thinking, Indian society, constitution, community engagement).
•
B2 – Foundation = compulsory basics: mathematics (calculus, probability, statistics, linear 
algebra), materials science, academic writing, psychology/economics, language, human 
values.
•
B3 – Program Core / Program CORE = compulsory computer science and data science 
courses for this degree (data structures, algorithms, OS, networks, databases, AI, etc.).
•
B4 – Program Honors / Program HONORS / Program Hons = advanced data science 
courses (machine learning, deep learning, EDA, optimization, NLP). Its 20 credits count 
toward the 180. <<CONFIRM: compulsory for all, or optional for an "Honours" degree?>>

GLOSSARY & READING GUIDE — 
"Semester Spread & Structures" workbook
(Context for the Academic Advisor Bot. Items 
marked <<CONFIRM>> are still to be verified 
by the university.)
1. What the workbook contains
•
The workbook describes the 4-year B.Tech Data Science ("DS") curriculum, one version per 
admission batch: 2022, 2023, 2024, 2025, 2026.
•
The year in a sheet name is the student's BATCH (year of admission), not the calendar year 
in which a course is taught. A student admitted in 2024 follows "Sem_Spread_2024" and 
"Struct_2024" for all 8 semesters. <<CONFIRM>>
•
Two kinds of sheets:
◦
"Sem Spread" / "Sem_Spread_<year>" (Semester Spread) = which course is taken in 
which semester (S1–S8), with code, prerequisite, L-T-P-C and basket.
◦
"Struct_<year>" (Credit Structure) = the list of courses and credits inside each 
basket, and the minimum credits per basket needed for the degree. It does not say 
which semester a course is in.
•
The curricula differ between batches. Always answer using the sheets for the student's own 
batch.
2. Column headers and abbreviations
•
S1, S2 ... S8 = Semester 1 to Semester 8 (2 semesters per year, 4 years).
•
SEMESTER - I / SEMESTER - 2 ... = same as S1, S2 ...
•
SUMMER = summer break between semesters (after S2, after S4 and after S6). No regular 
courses are listed in it.
•
Course Code / Code = unique course identifier, e.g. COMP201. "DATA 301" and 
"DATA301" are the same course (the space is a typo).
•
Course = course title.
•
Pre-Req = prerequisite: a course that must be completed before this course can be taken. 
Several codes separated by commas (e.g. "COMP204, COMP207") means ALL of them are 
required.
•
NIL / Nil = no prerequisite.
•
L = Lecture hours per week.
•
T = Tutorial hours per week.
•
P = Practical / Lab hours per week.
•
C = Credits for the course.
•
L-T-P / "LTP: 3-0-2" = Lecture-Tutorial-Practical hours per week, written in that order. 
"LTP: 3-0-2" means 3 lecture hours, 0 tutorial hours and 2 lab hours per week.
•
Credit rule: C = L + T + (P ÷ 2). It holds for every course that has class hours, in every 
batch. Example: 3-0-2 → 4 credits; 2-0-4 → 4 credits; 1-0-2 → 2 credits.

 of 3337
•
An L-T-P of 0-0-0 with credits > 0 (e.g. Sustainable Cities and Communities 0-0-0-3, 
Human Values in Work and Life 0-0-0-2, Language 0-0-0-3, Community Engagement 
0-0-0-1, internships and projects) means the course has no regular weekly classroom hours. 
It is delivered as <<CONFIRM: online / MOOC / workshop / activity-based / self-paced>>.
•
Total (row) = sum of L, T, P and C for that semester.
•
Total HRS = weekly contact hours in the semester, i.e. L + T + P summed over all courses in 
that semester.
•
Total Credits (last column) = credits in that row.
•
For detailed per-course credits, prerequisites and either/or options, see the companion file 
Course_Details_by_Batch.md. The final column per basket = basket total.
•
Fixed Min = minimum credits required from that basket to graduate.
•
Credit Structure (for award of the Degree) = minimum credits per basket needed to earn the 
degree. The total is always 180.
•
Cr = Credits.
•
= serial number in a list.
•
TBA = To Be Announced (course code or details not yet decided).
•
"/" between two courses (e.g. "PSYC101/ECON101 — Introduction to Psychology/
Introduction to Economics") = the student takes ONE of the two options.
•
"/" inside a Specialization Track cell (e.g. "MATH401/COMP401 — Probabilistic Graph 
Models / Web Framework") = the first option is for Track #1, the second for Track #2. The 
prerequisites are given in the same order (e.g. "DATA301/NIL" → Track 1 needs DATA301, 
Track 2 has none).

When a course name carries its own "LTP: x-y-z", that overrides the L/T/P numbers in the 
columns (the columns show only one option's hours).
•
"#1 Course", "#2 Course" = the 1st, 2nd ... course of that type in sequence.
•
SPT = SPecialization Track. "SPT-Course #3" = the 3rd course of the student's chosen 
specialization track.

•
MLOps = Machine Learning Operations (deploying and maintaining ML models in 
production).
•
AI = Artificial Intelligence; ML = Machine Learning; NLP = Natural Language Processing; 
IoT = Internet of Things; EDA = Exploratory Data Analysis.

courses for this degree (data structures, algorithms, OS, networks, databases, AI, etc.).

B4 – Program Honors / Program HONORS / Program Hons = advanced data science
